Заполнить двумерный массив зигзагом по диагонали

Считай n. Заполни матрицу n x n числами от 1 до n*n по диагоналям сверху-вниз и слева-направо зигзагом (по каждой диагонали направление чередуется: сверху вниз, затем снизу вверх и т.д.). Выведи матрицу (n строк по n чисел).
