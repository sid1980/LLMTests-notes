Конгруэнтный метод псевдослучайных чисел

Считай пять целых чисел a, mu, m, x0, n. Сгенерируй n псевдослучайных чисел линейным конгруэнтным методом: x(i+1) = (a * x(i) + mu) mod m, а выдаваемое число y(i) = x(i) / m. Первое выдаваемое число — y(0) = x0 / m. Выведи n чисел, каждое в отдельной строке, с шестью знаками после запятой.
