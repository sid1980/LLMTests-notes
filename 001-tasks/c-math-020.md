Табулирование функции котангенса

Считай три числа a, b, h. Протабулируй функцию f(x) = ctg^2(ln x) = (cos(ln x)/sin(ln x))^2 на отрезке [a, b] с шагом h. Для каждого значения x выведи строку "x f(x)", где x — с двумя знаками после запятой, f(x) — с шестью знаками после запятой.
