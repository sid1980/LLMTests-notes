Перестановка строк и столбцов

Считай n, затем квадратную матрицу n x n. Переставь строки и столбцы так, чтобы элемент с наибольшим по модулю значением оказался в правом нижнем углу (сначала поменяй местами его строку с последней, затем его столбец с последним). Выведи полученную матрицу.
