Произведение матрицы на вектор

Считай m и n, затем матрицу m x n из целых чисел, затем вектор из n целых чисел. Вычисли произведение матрицы на вектор (вектор-столбец из m чисел). Выведи в первой строке полученный вектор (через пробел), во второй — максимальный элемент этого вектора.
