Манипуляции с битами

Считай четыре целых числа x, y, m, n (0 <= m,n <= 32, x и y — 32-битные беззнаковые). Выполни: (1) в числе x замени младшие m бит на старшие m бит числа y (если m = 0 — без изменений); (2) инвертируй n младших бит в числе y. Выведи: в первой строке исходные x y m n через пробел, затем строку "x = <32-битное двоичное>" и строку "y = <32-битное двоичное>" для полученных значений.
