Квадратная матрица, главная и побочная диагонали

Считай n, затем квадратную матрицу n x n. Найди минимальный элемент среди элементов ниже главной диагонали (i > j) и максимальный элемент среди элементов выше побочной диагонали (i + j < n - 1). Поменяй их местами. Выведи: в первой строке индексы (строка, столбец, нумерация с нуля) минимального элемента, во второй — индексы максимального, затем полученную матрицу.
