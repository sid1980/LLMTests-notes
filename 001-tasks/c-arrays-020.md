Сортировка массива двумя способами

Считай n, затем n целых чисел. Отсортируй массив по возрастанию двумя способами (сортировкой выбором и шейкер-сортировкой). Выведи в первой строке отсортированный массив через пробел, во второй — количество сравнений сортировки выбором (для n элементов оно равно n*(n-1)/2).
