Номер минимального элемента, произведение, преобразование

Считай n, затем n целых чисел. Выведи: (1) номер (нумерация с 1) минимального элемента; (2) произведение элементов, расположенных между первым и вторым отрицательными элементами (если отрицательных меньше двух — выведи 0); (3) преобразованный массив: сначала элементы, модуль которых не превышает 1, затем все остальные (порядок внутри групп сохраняется).
