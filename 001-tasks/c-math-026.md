Точки пересечений линий

Считай коэффициенты a, b, c, d, k. Найди точки пересечения линий y = a*x^2 + b*x + c и y = d*x + k, то есть реши уравнение a*x^2 + (b - d)*x + (c - k) = 0. Если два корня — выведи их по возрастанию через пробел; один корень — выведи его; нет решений — выведи "no roots". Значения выводи с шестью знаками после запятой.
