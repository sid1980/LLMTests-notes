Итерационная формула корня кубического

Считай вещественное число x. Вычисли кубический корень из x по итерационной формуле y(i+1) = 0.5 * (y(i) + 3*x / (2*y(i)^2 + x/y(i))), начальное приближение y(0) = x, итерации прекратить при |y(i+1) - y(i)| < 1e-5. Выведи результат с шестью знаками после запятой. Для x = 0 выведи 0.
