# Coding Ladder Benchmark — release notes

Небольшой бенч без зависимостей для **локальных LLM на кодинг + tool-use**. Код модели
**реально исполняется** на тестах (не «оценка моделью»), в песочнице. Работает с любым
OpenAI-совместимым сервером: vLLM, LM Studio, llama.cpp, Ollama, text-gen-webui.
Только стандартная библиотека Python 3.8+ — ничего не устанавливать.

A small, dependency-free benchmark for **local LLMs on coding + tool-use**. Model code is
**actually executed** against real tests (no LLM-as-judge), sandboxed. Works with any
OpenAI-compatible server. Python 3.8+ stdlib only.

## Что умеет / What it does

- **142 задачи**: код easy (12) / medium (60) / hard (40) + tool-use / function-calling (30).
  Засчитывается только полное прохождение всех тестов задачи.
- 🛡️ **Песочница** для кода модели (PEP 578 audit-хуки): без сети, без запуска процессов,
  без доступа к чужим файлам и переменным окружения. Каждая заблокированная попытка логируется.
  Самопроверка: `python run_ladder.py selftest`.
- 🧪 **`probe_sampler.py`** — за ~10 секунд проверяет по эффекту, что сервер РЕАЛЬНО применяет
  параметры запроса (temperature/top_k/seed/max_tokens), а не отбрасывает молча. Запускать ДО бенча.
- 🧠 **Честный учёт reasoning**: ловит «думанье» и через отдельные поля (`reasoning_content`/
  `reasoning`/`thinking`), и блоками `<think>…</think>` (в т.ч. незакрытыми и с подставленным
  сервером тегом). В отчёте — сколько думала и о чём.
- 📊 **HTML-отчёт**: все прогоны рядом (ваши + эталонные), сортировка, маркеры галлюцинаций
  (обрыв по лимиту / цикл / пустой ответ / зависание кода), детализация по каждой задаче.
- 🔁 **Мульти-прогон** с усреднением по сидам + блок `conditions` (сэмплер/режим/лимиты) в
  каждом json — любой чужой результат самопроверяем на сравнимость.
- 🖥️ Запуск: веб-панель в браузере, терминальное меню или чистый CLI.

## Что нового в этой версии / What's new

- 🧠→⚠️ **Reasoning в non-think теперь честно помечается несравнимым.** Раньше тест пытался
  «чинить» non-think токеном `/no_think` в промпте — но в новых Qwen (3-2507+) он не действует
  (проверено: qwen3.5-9b думала 12/12), а сам меняет текст промпта и ломает сравнимость.
  Теперь `/no_think` по умолчанию **не шлётся** (можно вернуть для экспериментов: `LADDER_NOTHINK=1`),
  а если модель думала в non-think — прогон в отчёте помечается **«⚠ НЕ сравнимо с эталоном»**.
  Надёжно выключить reasoning можно только на СЕРВЕРЕ (тумблер в LM Studio; `--reasoning-budget 0`
  у llama.cpp; `think:false` в нативном API Ollama).
- 🔎 **Детектор reasoning стал полнее**: ловит поле `thinking` (нативный Ollama), вариант
  `<thinking>`, несколько блоков подряд и случай, когда сервер сам подставил открывающий
  `<think>` в промпт (в ответ приходит только закрывающий `</think>`).
- 🔧 **Код из размышлений не теряется**: если слабая модель положила решение внутрь `<think>`,
  а `content` пуст — код берётся из размышлений и помечается флагом `🔧 код из размышлений`
  (зачёт с оговоркой, виден в отчёте).
- 🧪 Добавлен **`probe_sampler.py`** (проверка сервера перед прогоном).
- 📄 README и подсказки приведены в соответствие: `chat_template_kwargs` понимают vLLM и
  llama.cpp (`--jinja`), но не LM Studio/Ollama.

## Быстрый старт / Quick start

```bash
# 1) (по желанию) проверить, что сервер слушается параметров:
python probe_sampler.py 1234

# 2) прогнать бенч (порт vLLM 8000 · LM Studio 1234 · llama.cpp 8080 · Ollama 11434):
python run_ladder.py 1234 my-model all

# 3) открыть report.html (пересобирается сам после каждого прогона)
```

Подробности, все env-переменные и раздел безопасности — в **README.md**.

## Честное сравнение / Fair comparison

Чтобы цифры были сравнимы — **фиксируйте сэмплер** (по умолчанию зашит официальный Qwen
non-think: `temp 1.0 · top_p 0.95 · top_k 20 · min_p 0 · seed 42`). При публикации указывайте:
модель, квант/формат, сэмплер, think/non-think, число экспертов (для MoE). Прогон на другом
сэмплере или с думаньем в non-think помечается в отчёте несравнимым.

Лицензия задач и происхождение — см. README. Форкайте, добавляйте задачи, делитесь цифрами 🙂
